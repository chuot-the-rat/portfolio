## 4) Recruiter Scan Checks

### 10-second test
- [ ] Role is clear immediately.
- [ ] Best project is obvious.
- [ ] Work section is easy to find.

### 30-second test
- [ ] 2-3 strengths are obvious.
- [ ] UX/Product projects are distinguishable.
- [ ] Resume/contact handoff is clear.

### 2-minute test
- [ ] One case study clearly shows problem -> pivot -> decision -> outcome.
- [ ] Evidence is visible (not only claims).
- [ ] Role ownership is explicit and credible.
